Giới thiệu

Mình là Ameee, đang học lập trình nhúng. Mình làm việc chủ yếu với ESP32 và vi điều khiển, viết firmware bằng C/C++ và thích tối ưu thời gian thực.

Kỹ năng

  • C / C++
  • ESP32-S3
  • Arduino
  • Điều khiển PID
  • HTML / CSS
  • JavaScript
  • Git / GitHub

Dự án

Xe dò line tốc độ cao

ESP32-S3, đọc cảm biến bằng ADC DMA, điều khiển PD và máy trạng thái.

Trang web giới thiệu bản thân

HTML, CSS Flexbox/Grid và JavaScript thuần, đây chính là trang này.

Trạm đo nhiệt độ không dây

ESP32 đọc cảm biến, gửi dữ liệu qua Wi-Fi lên bảng hiển thị. (Mẫu, hãy sửa lại)
